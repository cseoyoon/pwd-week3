#계산기 소개
간단한 사칙연산 계산기 프로젝트

#실행 명령

npm install
npm run build

빌드 후 index.html을 웹 브라우저에서 열어 계산기 실행한다. 

#기본 계산 확인
12 → + → 3 → = 누른 후 15라는 예상 결과 값 확인

12 → − → 3 → = 누른 후 9라는 예상 결과 값 확인

12 → × → 3 → = 누른 후 36이라는 예상 결과 값 확인

12 → ÷ → 3 → = 누른 후 4라는 예상 결과 값 확인

#계산식과 초기화 확인
웹브라우저의 개발자 도구를 이용해 확인
디버그 실행 후 오른쪽 공간의 scope -> script 클릭

12, + , 3 , = 을 누른 후 input, stored, operator, waiting, hasOperand가 정상 동작함을 확인 

#오류와 복구 확인

AC -> 1 -> 2 -> 0 -> = 를 누른 후
Error 와 "0으로 나눌 수 없습니다."가 표시되는 것을 확인함.

그 후 숫자 6을 누르고 오류 설명 사라진 후 6이 나오는 것을 확인함

#연속 입력과 작은 화면 확인

2 → + → 3 → × → 4 → = 누른 후 입력 순서대로 계산된 20이라는 결과 값 확인

2 → + → = 누른 후 2가 유지됨을 확인

2 → + → 3 → = → = 누른 후 반복 계산 없이 5가 유지됨을 확인

2 → + → × → 3 → = 누른 후 6을 결과값으로 가짐을 확인

200 → + → 10 → % → = 누른 후 200.1을 결과값으로 가지는 것을 확인
