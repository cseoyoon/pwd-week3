# 계산기 소개

간단한 사칙연산 계산기 프로젝트

# 실행 명령

```bash
npm install
npm run build
```

빌드 후 `index.html`을 웹 브라우저에서 열어 계산기를 실행한다.

# 기본 계산 확인

| 테스트 항목 | 입력               | 예상 결과 |
| ------ | ---------------- | ----: |
| 덧셈     | `12 → + → 3 → =` |  `15` |
| 뺄셈     | `12 → − → 3 → =` |   `9` |
| 곱셈     | `12 → × → 3 → =` |  `36` |
| 나눗셈    | `12 → ÷ → 3 → =` |   `4` |

# 계산식과 초기화 확인

웹 브라우저의 개발자 도구를 이용해 계산 상태를 확인한다.

| 테스트 항목   | 입력 / 방법                     | 확인 내용                                                                  |
| -------- | --------------------------- | ---------------------------------------------------------------------- |
| 계산 상태 확인 | 디버그 실행 → `Scope` → `Script` | 내부 계산 상태 확인                                                            |
| 계산식 입력   | `12 → + → 3 → =`            | `input`, `stored`, `operator`, `waiting`, `hasOperand`가 정상적으로 변경되는지 확인 |

# 오류와 복구 확인

| 테스트 항목  | 입력                       | 예상 결과                           |
| ------- | ------------------------ | ------------------------------- |
| 0으로 나누기 | `AC → 1 → 2 → ÷ → 0 → =` | `Error` 및 `"0으로 나눌 수 없습니다."` 표시 |
| 오류 복구   | 오류 상태에서 `6` 입력           | 오류 메시지가 사라지고 `6` 표시             |

# 연속 입력과 작은 화면 확인

| 테스트 항목    | 입력                      |  예상 결과 |
| --------- | ----------------------- | -----: |
| 연속 연산     | `2 → + → 3 → × → 4 → =` |   `20` |
| 연산자 연속 입력 | `2 → + → =`             | `2` 유지 |
| `=` 반복 입력 | `2 → + → 3 → = → =`     |        |
